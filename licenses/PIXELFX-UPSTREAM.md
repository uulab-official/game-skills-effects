# PixelFX source snapshot

Source: https://github.com/patch-gg/pixelfx  
Commit: `a84159688af3ca37a4be05a0d422b94451b2e24e`  
Retrieved: 2026-11-02

`src/` and `tools/` are an unmodified snapshot of the upstream code and effects. `LICENSE` and `NOTICE.md` are retained from that snapshot. `package.json` identifies upstream version 0.3.0 and the Node 18+ requirement. The upstream gallery and its separately licensed Patch Pixel font are not included.

The UULab effects under `effects/pixelfx/uulab/` are maintained separately and run on this API. Gallery preview, exported sprite sheets, and actual in-game visual quality are different evidence; importing the sheet and verifying its event/timing in the target engine is still required.
